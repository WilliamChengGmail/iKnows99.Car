## 一、專案建置成果概述

本系統已依照您提供的全部實體畫面與業務邏輯完整建置完成：
1. **多車輛自動巡迴**：自動偵測並走訪帳號下所有車輛（小青、迷你綠、白玉苦瓜……），收錄完整車籍與油箱參數。
2. **三大核心分類與深層明細**：
   * 🔧 **保養/維修**：完整收錄日期時間、里程、總額、支付方式、標題、備註，以及工單中每一項零件規格、壽命、單價、數量、小計與備註。
   * ⛽ **加油紀錄**：完整收錄加油公升數、單價、油表指針位置，並備份系統計算的 6 大即時油耗指標（上次里程、行駛距離、油箱油量、上次油耗、成本/公里、用油量）。
   * 💰 **一般費用**：完整收錄自訂標題與 8 大類別選單（其他/洗車/停車/稅費/規費/保險/交通/旅程）。
3. **終端即時看板**：使用 Python `rich` 彩色動態看板即時顯示當前進度與日誌。
4. **雙重去重與增量支援**：結合原生 ID 與業務指紋複合鍵，未來可隨時再次執行進行增量同步。
5. **雙重結果驗收**：螢幕即時顯示各車筆數核對總表，並於 `PersonalDataCatch/Logs/` 自動歸檔帶時間戳記的詳細稽核日誌。

## 二、使用者操作步驟 (SOP)

### 方法一：一鍵滑鼠啟動（最推薦）
1. 開啟檔案總管，進入目錄：
   `d:\iKnows99.Car\PersonalDataCatch\`
2. 在 **`run.bat`** 檔案上按滑鼠左鍵點擊兩下。
3. 批次檔將自動檢測環境、安裝必要套件，並啟動主程式。

### 方法二：透過命令提示字元 (CMD / PowerShell)
在終端機中切換至專案資料夾並執行：
```bash
cd d:\iKnows99.Car\PersonalDataCatch
pip install -r requirements.txt
python main.py
```

## 三、執行過程中的人機協同

1. **瀏覽器自動彈出**：
   * 程式啟動後，會自動彈出一個可見的 Chrome 視窗，並自動連線至 `https://iknow99.com/car.manager`。
2. **手動完成 Google 登入（您唯一需要執行的動作）**：
   * 請在彈出的瀏覽器視窗中點選「Google 登入」。
   * 輸入您的 Google 帳號、密碼，並完成手機雙重驗證 (2FA)。
3. **自動化全權接手**：
   * 登入成功跳轉至管理頁面後，主程式會即時偵測到後台載入狀態。
   * 您無需再點擊任何網頁按鈕，程式會自動：
     * 巡迴左側車輛列表。
     * 自動進入「紀錄列表」。
     * 自動讀取頂部徽章總數進行驗收比對。
     * 逐頁、逐筆點開彈窗並完整存檔至 SQLite。
4. **驗收與日誌產生**：
   * 擷取完畢後，視窗自動關閉。
   * 終端機顯示精美的彩色總結報表。
   * 自動於 `PersonalDataCatch/Logs/` 儲存一份時間戳記詳細報告（例如：`Extraction_Report_20261124_104500.md`）。

## 四、資料庫驗收與檢視

資料庫存放路徑為：
`d:\iKnows99.Car\Database\iknow99_car.db`

### 內建資料表與視圖：
* `vehicles`：車籍與規格設定
* `maintenance_records`：保養維修主檔
* `maintenance_items`：工單零件細項
* `refueling_records`：加油歷程與即時油耗
* `other_expense_records`：一般費用與 8 大類別
* `v_all_expenses`：綜合所有花費之即時統計視圖（View）

您可以使用任何喜歡的 SQLite 檢視軟體（例如 VS Code SQLite Viewer、DBeaver、SQLiteStudio 等）直接連線瀏覽。
